# Turk.edu — поступление в Турцию из Казахстана

Русскоязычный сайт на Next.js 16 / React 19 / TypeScript: 10 университетов, сравнение, документы, календарь, бюджет и студенческий ВНЖ. Контакты: +7 771 585 2661, https://t.me/limyrqq. Информация проверена 30 сентября 2026 года; подборка редакционная, не официальный рейтинг.

## Опубликованный сайт

https://turk-edu-limyrqq.khadesovsultan.chatgpt.site

Сайт доступен публично через Sites. Каталог, сравнение, калькулятор и чек-лист работают. В опубликованной статической версии обращения принимаются через прямые ссылки Telegram/WhatsApp; серверная форма в этих исходниках подключается по инструкции ниже. Обновление GitHub само по себе не передеплоит сайт в Sites.

## Запуск

Требуется Node.js 22+ и npm. В каталоге проекта:

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Windows PowerShell: `Copy-Item .env.example .env.local`. Откройте http://localhost:3000. Для локальной разработки задайте `NEXT_PUBLIC_SITE_URL=http://localhost:3000`.

```sh
npm run lint
npm run typecheck
npm run build
npm run start
```

## Что работает

- Каталог с поиском, фильтрами по городу/направлению и сравнением до трёх вузов.
- Отдельные страницы всех 10 вузов с анализом и официальными источниками.
- Чек-лист документов с сохранением в localStorage и сбросом.
- Калькулятор обучения и проживания: 9/12 месяцев, сценарий скидки, ввод курса USD/KZT. Курс 500 — пример, не текущая котировка; калькулятор не включает все разовые расходы.
- FAQ, мобильная навигация, светлая/тёмная тема, плавная прокрутка Lenis на устройствах с мышью, поддержка reduced motion.
- Форма: общая валидация Zod на клиенте/сервере, согласие, honeypot, ограничение размера, проверка Origin, лимит 5 заявок / 10 минут.
- В разработке обращения записываются в `data/leads/*.json`, Telegram без ключей отключён. Эта папка исключена из Git и архива.
- Метаданные, OG-изображение, sitemap, robots, manifest, favicon, страницы ошибок, локальные шрифты, защитные HTTP-заголовки.

## Подключение формы и Telegram

1. Создайте бота через BotFather, получите токен. Не публикуйте его и не используйте префикс NEXT_PUBLIC.
2. Откройте чат с ботом и нажмите Start. Получите числовой `chat.id` из Telegram Bot API `getUpdates`; не сохраняйте ответ с токеном в Git. `@limyrqq` — ссылка для прямой связи, а не chat ID получателя бота.
3. Укажите `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `NOTIFICATION_ADAPTER=telegram` в `.env.local` или настройках хостинга.
4. Для production создайте Redis с REST API (например Upstash) и задайте `RATE_LIMIT_REST_URL`, `RATE_LIMIT_REST_TOKEN`.
5. Для Vercel задайте `DATABASE_ADAPTER=memory`. Это временный буфер, не постоянная база; доставленное сообщение Telegram является записью обращения. Для постоянного архива реализуйте адаптер `DatabaseAdapter` в `server/adapters/database.ts` с вашей БД.
6. Перезапустите/передеплойте сайт и отправьте тестовое обращение. Без токена, получателя или общего лимитера production-форма возвращает 503, предлагая прямую связь. Сообщение об успешной отправке показывается только после подтверждённой доставки Telegram.

Живую доставку Telegram нельзя проверить без ваших секретов; при разработке внешние сообщения не отправлялись. В случае сбоя доставки запись помечается failed, но автоматической очереди повторов нет. В production используйте постоянную БД и очередь, если нужна гарантированная повторная доставка.

## Публикация на Vercel

Загрузите исходники в репозиторий https://github.com/Limyrqq/Turk.edu.git и импортируйте его в Vercel как Next.js. Root Directory — корень проекта. Install: `npm ci`, Build: `npm run build`. Укажите настоящий `NEXT_PUBLIC_SITE_URL=https://ваш-домен` и переменные формы выше, затем Deploy. Проверьте форму, OG, sitemap и контакты на опубликованном домене. Текущая публичная версия размещена через Sites по ссылке выше. Vercel — дополнительный вариант для запуска серверной формы.

Для собственного Node-сервера слушайте нужный интерфейс: `npx next start --hostname 0.0.0.0`; штатный `npm start` слушает только localhost. JSON-адаптер подходит одному локальному процессу с доступным диском, но не serverless-хостингу.

## Архитектура и изменение контента

- `content/universities.ts` — все цены, программы, даты и ссылки. `annualUsd` задаёт конкретный пример для калькулятора. Для ITU тарифы в TRY, поэтому его нет в USD-калькуляторе.
- `content/guide.ts`, `content/ui.ts` — тексты, шаги, документы, FAQ.
- `config/site.ts` — контакты, дата проверки, домен и навигация.
- `app/` — страницы, API, метаданные. `components/` — интерфейс.
- `server/adapters/` — база, уведомления, авторизация, платежи и аналитика; `server/services/` — сценарий сохранения заявки.
- `lib/lead-schema.ts` — правила формы. `server/rate-limit.ts` — общий REST-лимитер и локальный fallback только для разработки.
- `public/istanbul.svg` — исходная авторская иллюстрация; `istanbul.webp` — компактная версия. Поместите изображения в `public/raw/` и запустите `npm run optimize-images`: оптимизированные WebP/AVIF появятся в `public/images/`.

Платежи, авторизация и аналитика оставлены отключёнными интерфейсами. Изменение ENV само по себе не подключает провайдера: сначала реализуйте соответствующий адаптер, серверную проверку сессии/подписи webhook и интеграционные тесты. Payments webhook сейчас возвращает 501. Сайт не принимает платежи и не заявляет наличие личного кабинета. Аналитические и рекламные cookies отсутствуют; чек-лист сохраняет только отметки на этом устройстве.

## Обновление справочника

Проверяйте официальные страницы перед каждой кампанией. Большинство указанных наборов 2026 уже закрыто; сроки 2027 не следует выводить из прошлогодних как подтверждённые. Стоимость зависит от факультета, языка, года зачисления и квоты. У Hacettepe и Istanbul University нет подтверждённой здесь актуальной цены — сайт прямо предлагает её уточнить.

Безвизовый режим граждан Казахстана 90/180 дней не заменяет условия регистрации в вузе и студенческой визы. ITU в объявлении 2026 требует студенческую визу. ВНЖ оформляется по официальной процедуре e-Ikamet; окончательный перечень документов индивидуален. Услуги сопровождения не гарантируют зачисление, стипендию или ВНЖ.

Перед публикацией владелец должен указать актуальные данные оператора обработки обращений в `/privacy`, обеспечить обработку запросов на удаление, доступ к базе и сообщениям только ответственным лицам. Страница описывает фактическую конфигурацию, а не обещает автоматическое удаление записей.

## Проверки и ограничения

`npm run lint` и `npm run build` проходят. Браузерные проверки: 16 страниц + 404, один h1, фильтр медицины, сравнение, сохранение чек-листа, адаптивность 360/768/1280/1920, отсутствие ошибок JavaScript, axe, ответы API 201/400/403/503. Отчёты и превью находятся рядом с архивом исходников. Lighthouse измеряет локальный production-сервер с мобильным throttling; результат зависит от нагрузки компьютера. Живые платёжные, почтовые и Telegram-аккаунты не подключены.
